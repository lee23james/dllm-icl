## 关键数据结构流转

### 1. Anchor和候选集生成阶段

```
train_ds (10000个样本)
    ↓
RandSampler.sample()
    ↓
sampler_result = {
    "anchor_set": [100, 250, 500, ...],  # 5000个anchor索引
    "candidate_set": {
        100: [10, 20, 30, ..., 1000],    # anchor 100的64个候选
        250: [15, 25, 35, ..., 2000],    # anchor 250的64个候选
        ...
    }
}
```

### 2. 单个Anchor的ICD生成过程

```
输入:
  anchor_data = train_ds[100]  # isquery=1
  candidate_set = [train_ds[10], train_ds[20], ..., train_ds[1000]]  # 64个候选

初始化:
  candidateidx2data = {
      10: train_ds[10], 20: train_ds[20], ..., 1000: train_ds[1000],
      100: anchor_data  # query
  }
  test_data_id_list = [[100]]

Step 1 (添加第1个ICD):
  当前序列: [100]
  候选: [10, 20, 30, ..., 1000] (64个)
  插入位置: [0, 1] (no_order模式)
  组合数: 64 × 2 = 128
  评分: get_info_score(128个组合)
  选择: topk(2) → [[20, 100], [67, 100]]

Step 2 (添加第2个ICD):
  序列1: [20, 100]
    候选: [10, 30, 40, ..., 1000] (排除20, 100)
    组合: 62 × 2 = 124
    结果: [[20, 45, 100], [20, 67, 100]]
  
  序列2: [67, 100]
    候选: [10, 20, 30, ..., 1000] (排除67, 100)
    组合: 62 × 2 = 124
    结果: [[67, 20, 100], [67, 45, 100]]
  
  Beam filter: 从4个序列中选择top-2
  结果: [[20, 45, 100], [20, 67, 100]]

Step 3, Step 4: 类似过程...

最终: [[20, 45, 67, 89, 100], [20, 45, 67, 90, 100]]
```

## 数据量估算

假设：
- 训练集大小：10000
- anchor数量：5000
- 每个anchor的候选数：64
- few_shot_num：4
- beam_size：2

**计算量**：
- 每个anchor的评分次数：约 64×2 + 63×2 + 62×2 + 61×2 = 500次
- 总评分次数：5000 × 500 = 2,500,000次

**优化**：
- 使用批量评分（batch_size=16）
- 使用缓存机制（sampler缓存）
- Beam Search减少搜索空间
